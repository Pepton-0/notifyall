# notifyall

windows10以上の環境にて、画面上のあらゆるUIに通知アイコンを取り付けるジョークアプリです。
vibe codingなんで中身は適当です。
私はLINEの通知が一番嫌いです。

## 使い方

### 起動方法

1. releaseからzipをダウンロード、解凍。
2. 中のnotifyall.exeを起動。

### 操作方法

アイコンの表示・非表示の切り替えは、タスクトレイに新たに追加されたnotifyallアイコンを右クリックし、中の表示/非表示を押すことで可能。

### 終了方法

タスクトレイに新たに追加されたnotifyallアイコンから終了を選択。

### アプリクラッシュ時

何らかの要因でアプリが強制終了されたとき、一部の通知アイコンが取り残されたままになります。
その時はアプリを再起動して正規の手順で終了するかもしくはPC再起動をすることで、クリーンなデスクトップ環境へ戻れます。
